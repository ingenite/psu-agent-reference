# Report navigation wireframes

PSU dashboards/apps use overlapping terminology with React and CSS components.
I have found incremental, supervised additions improve accuracy and velocity in
later implementations.

Open [the three proposed layouts](report-navigation.html) in a browser;
`report-navigation.source.html` is the editable source.

- **Cards — selected:** keeps each report's description and action together.
- **Directory — ruled out:** wide rows require too much mouse travel to Open.
- **Direct report menu — ruled out:** navigation gets cluttered quickly,
  especially with long titles or titles that need explanation.

These are design sketches, not verified PSU component behavior.
